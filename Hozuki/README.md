# Clã Hōzuki · Shinobi World BR 18.11.74

Versão de teste com três modelos animados de água translúcida. Corpo Hídrico cobre parcialmente braços, ombros e flancos. Água Hand amplia o braço direito. Água Gigante amplia a silhueta humanoide.

- Pacote com addon, três projetos Blockbench, texturas e arquivos de integração. [Baixar Hozuki.zip](https://github.com/Forge-Studio0/models/raw/refs/heads/main/Hozuki/Hozuki.zip)
- Addon para a base original 18.11.64 do briefing. [Baixar Hozuki.mcaddon](https://github.com/Forge-Studio0/models/raw/refs/heads/main/Hozuki/Hozuki.mcaddon)
- Addon para quem usa a 18.11.73 com Iburi, Aburame e Kaguya. [Baixar Hozuki_Cumulativo.mcaddon](https://github.com/Forge-Studio0/models/raw/refs/heads/main/Hozuki/Hozuki_Cumulativo.mcaddon)
- Geometrias, texturas, animações, arquivos BP/RP e aplicador para as duas bases. [Baixar Hozuki_Integracao.zip](https://github.com/Forge-Studio0/models/raw/refs/heads/main/Hozuki/Hozuki_Integracao.zip)
- Três projetos editáveis com textura incorporada e animações. [Modelos Blockbench](Modelos_Blockbench/)
